# Website — Лотос

Локальная статическая презентация дома Tan House. Активная страница собирается Astro из существующих визуализаций; сервер, авторизация, каталог и оплата не подключены.

## Запуск и проверка

Из корня `lotos-site`:

```sh
bun run dev:lotos
bun run test:lotos
bun run typecheck:website
bun run build:website
bun run --cwd website test:build-contracts
bun run preview:lotos
```

Готовый сайт — `website/dist`, preview — http://127.0.0.1:4325/. После изменений в коде для preview нужна новая сборка и перезагрузка страницы. Это единственный workspace проекта.

## Движение и интерактивность

GSAP 3.15: ScrollTrigger управляет прогрессом 14 сцен; LatestSeek последовательно применяет только актуальную перемотку. Подпись комнаты анимируется отдельно от скролла и остаётся читаемой при остановке. Видео загружается в фоне через 200 мс после window.load либо раньше при приближении к экскурсии: 720p desktop / 540p на узком экране. При Save-Data сохраняется загрузка только при приближении; reduced-motion и фото-режим не запускают фоновую загрузку. Без JavaScript видео не запрашивается.

ScrollSmoother включён при ширине от 900 px, высоте от 700 px, точном указателе с hover и отсутствии reduced-motion. Сглаживание — 0,7 секунды, без snap и без изменения touch-прокрутки. Инициализация общая для страницы и React-экскурсии, до их ScrollTrigger. Когда сглаживание активно, сцену фиксирует ScrollTrigger; иначе единственный владелец фиксации — CSS sticky. Не добавляйте второй pin поверх существующего.

Контент находится в `#smooth-wrapper > #smooth-content`; диалог просмотра и ссылка пропуска — снаружи. При открытии диалога сглаживание ставится на паузу. Прямой выбор комнаты позиционирует страницу сразу; обычные якоря перемещаются плавно. Фото-режим, reduced-motion и ошибка MP4 оставляют доступ ко всем сценам. Изменение media query и размонтирование очищают связанные анимации.

План содержит 12 интерактивных зон по исходному изображению. Выбор синхронизирует подсветку, список, превью, площадь и переход к сцене. SVG обрезает внешние поля исходного скриншота без перерисовки геометрии дома.

Галерея сразу показывает четыре выбранных кадра; ещё десять доступны через раскрытие. Нативный dialog поддерживает Escape, стрелки, удержание и возврат фокуса. Flip связывает карточку с увеличенным изображением. Без JavaScript план и галерея сохраняют обычные ссылки на файлы, а форма отключена с пояснением.

Демо-форма использует существующие shadcn/ui-примитивы, проверяет обязательные поля и имитирует завершение; сетевых запросов и хранения данных нет.

## Контент и ограничения

Характеристики — `src/data/house.ts`. Монтажная шкала `src/data/tour.json` генерируется внешним скриптом, не редактируется вручную. Главы и связи с комнатами находятся в модуле экскурсии. Инструкция подготовки медиа — в [корневом README](../README.md).

Изображения и видео — концептуальные визуализации. Сумма внутренних помещений 114,28 м², терраса 20,50 м² указана отдельно; общая площадь проекта требует подтверждения. Не добавляйте неподтверждённые цены, комплектацию, контакты и отзывы.

Обложка Open Graph подготовлена из существующего фасада. Пользовательский домен не выбран: canonical, og:url и абсолютный og:image необходимо настроить при его подключении. Сайт опубликован на https://tan-house-lotos.bullbashechka.workers.dev. Деплой из корня: `bun run deploy`; `worker/media.js` обеспечивает Range для MP4, остальное обслуживается Cloudflare Static Assets. Шаблонные 3D-компоненты, Storybook и инфраструктура удалены; сохранены только компоненты текущего сайта.

План, журнал проверок и оставшиеся сценарии: [LOTOS_PREMIUM_PLAN.md](../docs/LOTOS_PREMIUM_PLAN.md).

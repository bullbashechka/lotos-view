# Tan House — Лотос

Локальный сайт-презентация: скролл перематывает видео, читаемые подписи расположены под кадром. GSAP согласует появления заголовков и переходы; на компьютере работает плавная прокрутка. На телефоне кадр остаётся целым и сохраняется обычный скролл. Есть пять глав, выбор комнаты, фото-режим, интерактивный план и галерея внутри сайта. Демо-форма заявки (#request) проверяет имя и телефон и имитирует завершение; данные не передаются и не сохраняются.

## Открыть

Опубликованный сайт: https://tan-house-lotos.bullbashechka.workers.dev

Рабочая сборка: http://127.0.0.1:4325/ (пока запущен сервер).

Из папки `lotos-site`:

```sh
bun install --frozen-lockfile
bun run build:website
bun run preview:lotos
```

Для редактирования: `bun run dev:lotos`. Адрес печатается при запуске; занятые порты не освобождаются принудительно. Node 24 и Bun 1.3.14 использованы в текущей проверке. Не открывайте `index.html` через file:// — нужен локальный сервер.

## Деплой

`wrangler.jsonc` публикует `website/dist` вместе с обоими MP4 в Worker `tan-house-lotos`. `website/worker/media.js` обеспечивает перемотку через HTTP Range; для этого он читает ролик в память (максимум 18,3 МБ). Остальные assets обслуживаются напрямую. Запросы MP4 учитываются в лимитах Workers. R2 и KV не подключены; новая подписка не требуется.

Видео начинает загружаться в фоне через 200 мс после window.load либо раньше при приближении к экскурсии. При Save-Data сохраняется загрузка при приближении, при reduced-motion используется фото-режим. Скорость готовности зависит от соединения посетителя.

```sh
bunx wrangler@4.129.0 login
bun run deploy
```

Wrangler запускается через Bun с фиксированной версией, без новой зависимости проекта. `bun run deploy` выполняет локальные проверки, сборку, dry-run и публикацию; `bun run deploy:check` — всё до публикации. Авторизация хранится средствами Wrangler вне репозитория. Автодеплой и пользовательский домен пока не настроены.

## Материалы и изменения

План и журнал реализации: [премиальное оформление и GSAP](docs/LOTOS_PREMIUM_PLAN.md). Основные изменения реализованы; оставшиеся браузерные проверки явно перечислены в журнале.

- `website/src/data/house.ts` — характеристики и названия.
- `website/src/data/tour.json` — сгенерированная шкала времени; вручную не менять.
- `website/src/features/tour/` — управление кадрами и текстом.
- `website/src/styles/global.css` — тема и адаптивное оформление.
- `website/public/media/` — готовое видео 720p, облегчённое 540p, постеры и план.

Исходные 14 роликов остаются в соседней папке `lotos/syntx/returns`. Монтаж: 41,25 секунды, 24 кадра/с, растворения по 0,25 с, без звука. Сохранённая скорость исходников; непрерывный проход через двери не генерировался.

Для повторной подготовки медиа запускать из родительской папки `tan house`:

```sh
lotos/.venv/bin/python lotos/scripts/assemble_site_tour.py
```

Python-зависимости перечислены в `lotos/requirements.txt`. После изменения исходных роликов снова выполните сборку сайта. Скрипт перезаписывает только производные материалы, исходники не меняет.

## Проверка

```sh
bun run test:lotos
bun run typecheck:website
bun run build:website
bun run --cwd website test:build-contracts
```

`bun run check` запускает все проверки текущего сайта: типы, тесты, сборку и статические контракты. Общие `dev`, `build`, `preview`, `test` и `typecheck` также работают только с сайтом.

Новая GSAP-версия: 7 тестов механики/навигации и 2 статических контракта, проверка типов, сборка и архитектура. В Chrome проверены выбор всех 14 сцен со сглаживанием, сохранение комнаты при фото → видео, читаемость подписи при остановке, 12 зон плана, увеличение плана с Escape/возвратом фокуса, открытие и переключение галереи, размеры 390×844 и 360×800 и обязательность полей формы.

После очистки шаблона повторно прошли чистая установка по lock-файлу и `bun run check`: 9 тестов, типы без замечаний, сборка. В Chrome проверены выбор комнаты, фоторежим, план, галерея и успешное завершение/повтор демо-формы. На 390×844 и 360×800 нет горизонтального переполнения. Расширенные reduced-motion/no-JS/сбой MP4, короткий экран, настоящий телефон и Safari для новой версии полностью не перепроверены; подробности в журнале.

## До финального запуска

Уточнить общую площадь (подписи плана суммарно дают 114,28 м²), комплектацию и контакты; согласовать финальные тексты, проверить реальные телефоны и выбрать домен. Изображения и видео — концептуальные визуализации, не фотографии построенного объекта. Обновлённый Word-отчёт находится в соседней папке `lotos/report`.
